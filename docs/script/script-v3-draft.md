## 0. 三條原則

1. **不確定才會恐怖。** 玩家要一直在兩種恐懼之間拉扯：開門可能是救贖，也可能是把「那個東西」放進來。門外的人知道你的名字，但他也說出不該說得出的話。
2. **盲區不只在螢幕裡。** 你背對房間時，房間也會變。最可怕的一幕，是監視器拍到「你自己」。
3. **克制。** 不靠煽情台詞，不交代所有細節。結局用畫面說話。

**真相（與舊版相同，不在遊戲裡一次說明）**
- 三年前的今晚，隧道火災，消防員林志遠一路破拆到中央控制室的防爆門外，要救值班員陳哲（阿哲）。
- 阿哲怕煙灌進來，切斷主排風，反鎖了門，兩人都死了。
- 阿哲困在 02:00 → 02:14 的循環裡，每一輪都把便利貼寫給下一輪的自己。

**新的關鍵設定：對講機裡的聲音是三年前的「錄音」**
- 志遠的話是固定的：他三年前就說過這些話。你的回應，其實是在對一段回憶說話。
- 這解釋了所有「不對勁」：他會重複你的話、在你開口前回答、手上沒拿對講機卻在說話。
- 玩家不知道這個設定，只會覺得**門外的東西不像人**。
- 你改變不了他說了什麼，只能改變你做了什麼：開不開門。

## 2. 結構與結局

```
02:00  醒來，便利貼，親手鎖門
02:03  對講機 1（回應／沉默）
02:05  主排風逆流 → 切斷 → 背後敲門、門縫滲煙      ★ 可以開門 ──→ 結局 C「回頭」
02:06  抽屜（可選，隨時可看）
02:08  對講機 2（他叫你的名字）
02:10  濕腳印
02:12  聽覺真空 → CAM-00
02:13  對講機 3（第二個聲音）                    ★ 最後一次可以開門 ──→ 結局 B「02:15」
02:14  跳電 → 廊道 → 復電 → 高清真相 → 錄音 → 終幕   ──→ 結局 A「交接」（循環）
```

| 結局 | 條件 | 基調 |
|---|---|---|
| **A 交接** | 一路都沒開門 | 循環。你成了監視器裡那個趴著的人 |
| **B 02:15** | 02:13 最後一通時開門 | 太遲了。他已經倒在門外，但時間第一次往前走 |
| **C 回頭** | 02:05 敲門時就開門 | 他帶你走出去。你可以回頭，但回頭會看見自己 |

- 第一輪多數人會聽便利貼的話走完 A，知道真相後才會想「如果我開門呢？」。
- 開門就是一場賭博：在你不知道真相的時候，**開門看起來就是在放怪物進來**。
