## 0. 修訂原則

1. **保留**：02:00 → 02:14 的值班、防爆門、隧道火災、盲區人影、聲音錯位、白車妄想、高清反轉、便利貼循環。

3. **真相由玩家拼出來**：減少大段說明文字。高清畫面只做「確認」，不負責「解釋」。
4. **門外的人有名字、有聲音、認識你**。
5. **選擇有後果**：三個結局，依「你有沒有開門、什麼時候開」決定。
6. 文字維持克制：短句、口語、不煽情；恐懼來自「他知道你的名字」，而不是怪物。

## 2. 新結構與三個結局

```
02:00 醒來 ─ 便利貼 ─ 親手鎖門
   │
02:03 對講機 1（可回應／沉默）
   │
02:05 通風逆流 → 切斷主排風 ─ 敲門＋門縫滲煙 ─ ★ 第一次可以開門 ──→ 結局 C「交接」
   │
02:08 對講機 2（可回應／沉默）
   │
02:13 對講機 3（可回應／沉默）──── ★ 最後一次可以開門 ──→ 結局 B「遲了一步」
   │
02:14 跳電 → 廊道（錶、日誌、雨衣）→ 復電 → 高清真相 → 錄音
   │
終幕：解除門鎖 → 濃煙、焦黑 → 寫下「鎖死防爆門。」 ──→ 結局 A「重演」（循環）
```

| 結局 | 條件 | 基調 | 長度 |
|---|---|---|---|
| **A 重演** | 從頭到尾沒開門（現有路線） | 循環，罪惡被「忘掉」 | 全程約 11–14 分 |
| **B 遲了一步** | 02:13 最後一通時去開門 | **放下**：他已經倒在門外，但循環第一次停止 | 約 6–7 分 |
| **C 交接** | 02:05 敲門、門縫冒煙時就開門 | **救贖**：你終於做了那一夜該做的事 | 約 4–5 分 |

- 開門的那一刻就是真相：直接看見**真實的**志遠（彩色、清晰），不需要經過第二、三幕。
- 第一輪多數玩家會聽便利貼的話，走完 A；知道真相後重玩，才會開始想「如果我開門呢？」。重玩的意義就在這裡。
- 「救贖」與「放下」不必二選一：**越早開門越接近救贖，太晚就只能放下。**
